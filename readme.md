Prompt Hub ｜ 您的 AI 灵感仓库
Prompt Hub 是一款专为 AI 创作者设计的提示词管理工具。它通过 GitHub Gist 实现免费、私密且高效的云端同步，确保您的灵感在多台设备间无缝衔接。

⚠️ 重要前提：您必须拥有 GitHub 账号
本工具的云同步功能完全建立在 GitHub 的基础设施之上。拥有一个 GitHub 账号是使用本工具的唯一前提条件。

数据归属：您的数据不存储在任何第三方服务器，而是存储在您自己的 GitHub 账号下。

完全免费：利用 GitHub 提供的 Gist 服务，无需支付任何存储费用。

私密性：除非您主动分享，否则您的提示词仓库默认是私密的，仅您可见。

如果您还没有账号，请先访问 GitHub 官网 完成注册。

🚀 配置指引
第一步：获取您的“云端钥匙” (Token)
注册账号后，您需要创建一个访问令牌（Token）来授权本工具读写您的 Gist 数据。

登录您的 GitHub 账号。

点击右上角头像 -> Settings（设置）。

在左侧菜单最底部找到并点击 Developer settings。

选择 Personal access tokens -> Tokens (classic)。

点击 Generate new token (classic)，在备注中填写 PromptHub。

核心操作：在权限列表中勾选 gist 选项。

点击页面底部的 Generate token。

立即复制保存生成的字符串。注意：一旦关闭此页面，您将无法再次看到它。

第二步：配置同步
打开 Prompt Hub 应用，点击右上角的 ⚙️ 同步设置。

GitHub Token：粘贴您刚才获取的字符串。

Gist ID：

首次使用：请保持留空，直接点击“保存配置”。系统会在您创建并保存第一个 Prompt 时，自动在您的 GitHub 下创建一个新的私有仓库。

更换设备：在其他设备登录时，请输入您第一台设备生成的 Gist ID（在同步设置面板可见）即可拉取现有数据。

💡 功能操作
新建内容：点击“+ 新建 PROMPT”即可开启全新编辑，系统已修复内容残留问题，确保界面干净。

自由排序：

电脑端：支持全方位插入。将卡片拖动至目标卡片的左、右、上、下边缘，即可精准改变位置。

手机端：长按卡片 0.6 秒触发微震反馈后，即可随意拖动位置。

重命名分类：在主页分类标题旁点击“重命名”，可一键修改该线下所有 Prompt 的分类名。

导出配置：在设置面板点击“导出配置”，可下载包含 Token 和 ID 的备份文件。

🛡️ 安全与免责声明
在使用本工具前，请务必知悉以下条款：

隐私保护：本应用为纯前端工具。您的 GitHub Token、Gist ID 及所有 Prompt 内容均直接存储在您的浏览器本地（LocalStorage）及您的个人 GitHub 账户中。开发者无法通过任何手段获取您的私钥或数据。

第三方依赖：同步功能依赖 GitHub 服务的稳定性。如因 GitHub 服务器宕机或 API 调整导致无法访问，本工具概不负责。

Token 安全：请妥善保管您的 Token。 请勿在公共设备上配置同步功能。如果您的 Token 泄露，请立即在 GitHub 后台吊销（Revoke）该令牌。

数据丢失：尽管有云端同步，仍建议定期通过“导出配置”功能备份您的重要数据。开发者不对因意外清空浏览器缓存或账号操作失误导致的数据丢失负责。
